# codigo

Código fuente del proyecto, organizado por área funcional. Cada subcarpeta corresponde a piezas que se programan y se prueban por separado en la Raspberry Pi, una por una:

- `vision/` — captura de video, identificación por asiento, manos levantadas, cola de participación, señales de atención.
- `voz/` — captura y reconocimiento de comandos de voz del docente, respuesta hablada del robot.
- `datos/` — registro y almacenamiento de datos de asiento, atención y participación.
- `dashboard/` — dashboard en el celular del docente y alertas.
- `reportes/` — reporte de fin de clase y sugerencia de material de refuerzo.
